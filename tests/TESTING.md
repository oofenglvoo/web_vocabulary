### 本轮修复的测试稳定性问题

1. **TC-EXTRA-001/005（加学确认框）**：原 `createPlanWithQuota1` 通过 UI 创建计划后直接修改 IndexedDB 改 `newPerDay=1`，再 `page.reload()` → 计划 ID 与硬编码 `plan=1` 不匹配，且 reload 后 live query 时序不稳定。改为通过 UI 的 NumberStepper 直接设置每日新词=1（点减号 9 次），并在点击"认识"后等待完成页 `今日学习已完成!` 出现，确保 `markWordStarted` 已写入 DB 再回首页验证弹窗。
2. **TC-ADD-002（多释义单词）**：保存后跳转 `/words`，但 live query 列表渲染存在时序竞争，`getByText('bank').click()` 在列表未渲染时超时。增加 `waitFor` 等待元素出现后再点击。
3. **同类问题修复**：TC-ADD-003、TC-DTL-001/002/003/005/006/008/009/010 均添加 `waitFor` 守卫，确保 live query 渲染完成后再交互。
